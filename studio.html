(01) Manifesto

Indian houses were built around a courtyard, a well and a shadow. We are not nostalgic about it — we simply think the logic still holds. Build for heat. Build for the hand. Build so it ages slowly and looks better doing it.

We keep a sample room in each studio — plaster boards, stone offcuts, timber in four finishes. Nothing is specified from a screen.
